# 使用指南

山风新页的核心体验：**壁纸随主题变，配色随壁纸变**。所有操作都围绕新标签页本身展开。

## 界面总览

新标签页从上到下依次是：

- **时钟 + 农历**（左上角区域）
- **搜索框**（居中，带搜索引擎切换与联想建议）
- **Dock 快捷方式栏**（底部，含「启动台」入口）
- **设置入口**（Dock 栏或右键菜单进入）

## 壁纸与主题

### 切换主题

点击设置 → 外观，或通过 Dock 栏的快捷入口切换 **亮色 / 暗色 / 跟随系统** 三种模式。

![主题模式](/images/lightanddark.webp)

### 更换壁纸

设置 → 外观中可分别为 **亮色主题** 和 **暗色主题** 上传独立的壁纸。切换主题时壁纸自动跟随，无需重复设置。

![壁纸预览](/images/bg1.webp)

内置壁纸仅作演示，你可以上传任意图片。壁纸以 Blob 形式存储在浏览器 IndexedDB 中，**只存本地，不会上传任何服务器**。

### 动态取色

更换壁纸后，界面主色调会自动从壁纸中提取（Material You 风格）：

- 壁纸之上的交互元素（搜索框、Dock）使用**毛玻璃**效果，保留壁纸可见性
- 覆盖层面板（设置、启动台）使用**不透明表面 + 阴影**，保证可读性
- 取色失败时自动降级为默认蓝紫色板，不会出现"难看"的兜底色

## 搜索

- 在搜索框输入关键词，回车直接搜索
- 点击搜索框左侧的搜索引擎图标，可**切换搜索引擎**（默认内置百度、必应、谷歌）
- 设置 → 搜索引擎中可**添加 / 编辑 / 删除**自定义搜索引擎（需要支持 `{keyword}` 占位符的搜索 URL）
- 输入 2 个字符以上时弹出**联想建议**（基于百度搜索建议，仅输入关键词，不包含个人信息）
- 搜索结果可在当前标签页或新标签页打开（设置 → 外观 → 搜索结果打开方式）

## Dock 快捷方式

底部 Dock 栏用于放置最常用的站点：

- **添加**：设置面板中或通过启动台卡片右键「添加到 Dock 栏」
- **排序**：右键快捷方式 → 左移 / 右移（已到最左 / 最右时菜单项置灰）
- **编辑**：右键快捷方式 → 编辑（修改名称 / 链接 / 图标）
- **删除**：右键快捷方式 → 删除
- **打开**：左键单击，在新标签页中打开

Dock 顺序即数组顺序，通过右键菜单的「左移 / 右移」相邻调整。

## 启动台

点击 Dock 栏的「启动台」图标，从底部滑入网站网格面板：

- 内置 12 个常用网站（GitHub、Gmail、YouTube、Notion、Figma 等），可自由增删改
- **左键点击**：打开网站并收起面板
- **右键卡片**：在新标签页打开 / **添加到 Dock 栏** / 编辑 / 删除

## 设置面板

点击 Dock 栏「设置」图标打开，包含四个分区：

| 分区 | 功能 |
| --- | --- |
| 外观 | 主题模式、壁纸（亮/暗分别设置）、搜索结果打开方式 |
| 搜索引擎 | 管理搜索列表，添加自定义引擎 |
| 备份 | 导出 / 导入配置（见下） |
| 关于 | 版本信息、开源链接 |

## 备份与迁移

设置 → 备份提供**纯本地**的配置导出 / 导入，不依赖任何云端服务：

- **导出**：一键下载 `shanfeng-backup-YYYY-MM-DD.json`，包含搜索引擎、Dock、启动台、主题等全部配置
- **导入**：选择备份文件后，可选择**覆盖导入**（以备份为准）或**合并导入**（去重追加备份中不存在的项）
- 导入成功后将自动刷新页面生效

::: tip 备份范围
壁纸图片（IndexedDB 中的 Blob）不包含在备份文件内，换设备后壁纸需重新上传。
:::

## 数据与隐私

| 数据 | 存储位置 | 是否上云 |
| --- | --- | --- |
| 配置（搜索引擎、Dock、启动台、主题） | localStorage | 否，纯本地 |
| 壁纸图片 | IndexedDB（`shanfeng-wallpaper` 库） | 否，纯本地 |
| 搜索联想词 | 仅运行期内存，实时请求百度建议接口 | 仅关键词请求，无历史记录 |

扩展权限最小化：Chromium 版仅申请 `activeTab` 权限（点击工具栏图标时临时读取当前页信息，用于收藏网页），无任何全站访问权限。
