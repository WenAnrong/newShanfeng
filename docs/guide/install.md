## 直接加载已构建产物

### Chrome 加载

1. 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载未打包的扩展程序」
4. 选择你存放浏览器插件的目录
5. 这样就可以加载这个插件了，打开新标签页即可看到山风新页
