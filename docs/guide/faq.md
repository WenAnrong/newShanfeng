# 常见问题

## 安装相关

### 加载后打开新标签页没有变化？

1. 确认加载的是 `extensions/Chromium` 目录（Chrome）或 `extensions/Firefox/manifest.json`（Firefox），不要选错目录
2. 尝试关闭并重新打开一个标签页（已打开的标签页不会自动替换）
3. 浏览器更新或重启后临时加载的扩展会失效，需要重新加载

### 为什么 Firefox 临时加载总提示版本过低？

Firefox 版要求 **142.0 及以上**（manifest 中 `strict_min_version` 的规定，MV3 新特性需要较新内核）。请升级 Firefox 或使用 Chrome / Edge。

### 可以上架到应用商店吗？

仓库代码即为完整扩展，遵循各商店的开发者上架流程打包提交即可。Chromium 与 Firefox 的 manifest 已按各自规范维护。

## 使用相关

### 为什么换壁纸后界面颜色没变？

动态取色需要一点时间（图片加载 + Canvas 采样）。如果长时间无变化，可能是壁纸为纯色或取色失败，此时会自动降级为默认蓝紫色板。

### 为什么某些网页图标显示不出来？

图标优先从网站获取 favicon，获取失败时使用 `favicon.im` 服务兜底。极少数站点两者都不可用时会显示占位图标，不影响使用。

### 搜索联想词为什么和百度搜索框不完全一样？

联想词接口由百度搜索建议提供，展示结果可能与百度首页略有差异，属正常现象。

### 我的数据存在哪里？会不会被上传？

所有数据（配置 + 壁纸）都存储在浏览器本地（localStorage / IndexedDB），不会上传任何服务器。唯一的网络请求是搜索联想词接口，仅发送输入的关键词。

## 备份相关

### 换电脑后怎么迁移数据？

设置 → 备份 → 导出 JSON 文件 → 新电脑安装扩展后导入即可。注意壁纸图片不包含在备份内，需在新设备重新上传。

### 导入备份会覆盖我现有数据吗？

导入时会弹窗让你选择：**覆盖导入**（以备份为准）或**合并导入**（只追加备份中有而本地没有的项）。误操作覆盖后暂无撤销功能，建议导入前先导出一份当前配置。

## 开发相关

### 想改代码 / 提 PR？

欢迎贡献！仓库文档在 `docs/` 下，开发者文档见[架构设计](../dev/architecture)、[决策记录](../dev/decisions)、[构建与发布](../dev/build)。本地运行：

```bash
npm install
npm run dev     # 开发预览（Vite dev server）
npm run build   # 构建扩展产物
```

项目采用 MIT 协议开源，代码可自由使用，保留版权声明即可。
